# Руководство пользователя: Сводный график дежурств

## 🎯 Назначение
Программа автоматически собирает графики дежурств из разных файлов в один документ Word.

## 🚀 Быстрый старт
1. Создайте папку и положите в неё все файлы графиков за нужный месяц (`.xlsx`, `.pdf`).
2. Запустите `Сводный график.exe` (или `python main.py`).
3. Нажмите **"Обзор..."** и выберите созданную папку.
4. Проверьте, что в списке файлов отобразились ваши графики.
5. Выберите **Месяц** и **Год** (должны совпадать с данными в файлах).
6. Выберите **Руководителя** и **Площадку** из выпадающих списков.
7. Нажмите **"🚀 Составить сводный график"**.
8. Результат появится в подпапке `Сводный график` внутри выбранной папки.

## ⚠️ Частые вопросы
**В: Программа пишет "Данные не найдены".**
О: Проверьте, что выбранный в программе месяц и год точно совпадают с теми, что написаны внутри файлов Excel/PDF.

**В: Врач не попал в график.**
О: Убедитесь, что его имя написано без опечаток и не совпадает со служебными словами (программа автоматически фильтрует заголовки). Проверьте сгенерированный `.xlsx` файл для детального аудита.

**В: Файл Word не сохраняется.**
О: Закройте файл `сводный_график_...docx`, если он открыт в Microsoft Word. Программа не может перезаписать открытый файл.

## ⚙️ Настройка списков
Чтобы добавить нового руководителя или площадку, откройте в Блокноте файлы в папке с программой:
- `spravochnik_rukovoditeli.txt` (формат: `Должность|ФИО`)
- `spravochnik_ploshadki.txt` (по одному названию на строку)
Сохраните файл в кодировке UTF-8 и перезапустите программу.
