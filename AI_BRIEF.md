# AI_BRIEF — Правила работы с проектом для ИИ

## 🧠 Контекст
Это медицинский проект для автоматизации составления сводных графиков дежурств. Точность парсинга имен и времени критична. Ошибки в именах (например, потеря 'Кодирова' из-за слова 'Код' в заголовке) недопустимы.

## 🛠️ Стек технологий
- **Язык:** Python 3.10+
- **UI:** CustomTkinter
- **Данные:** pandas, openpyxl
- **PDF:** pdfplumber (предпочтительно для извлечения таблиц), pypdf (резерв)
- **Документы:** python-docx

## 🚫 Табу (Строго запрещено)
1. **Не удалять и не менять логику `is_valid_doctor_name`** без веской причины. Там настроены исключения для фамилий (например, 'Кодиров').
2. **Не хранить реальные персональные данные (ФИО пациентов, точные графики)** в репозитории. Папка `data/` игнорируется в `.gitignore`.
3. **Не править сгенерированные документы вручную.** Вся документация генерируется через `service/docs/make_docs.py`.
4. **Не ломать модульную структуру.** Новый парсер добавляется в `parsers/`, а не в `main.py`.

## 📐 Соглашения по коду
- Все парсеры возвращают кортеж: `(data_dict, detected_dept, months_set, years_set)`.
- Время нормализуется функцией `normalize_time` из `core/utils.py` в формат `ЧЧ-ЧЧ` или `ЧЧ:ММ-ЧЧ:ММ`.
- Для ОАР буква смены (А/Р/Э) должна стоять *перед* временем (например, `А 16-09`).
- Для PDF-хирургии используется двухпроходный алгоритм или `extract_tables`, так как дата может стоять после имени врача.

## 🔄 Процесс изменений
1. Сначала обнови логику в соответствующем модуле (`parsers/`, `core/`).
2. Протестируй на файлах из `data/input/`.
3. Обнови `CHANGELOG.md` через `make_docs.py --force`.
4. Сделай коммит с префиксом: `fix:`, `feat:`, `refactor:`.
