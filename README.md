# 📊 Сводный график дежурств

Автоматическое объединение графиков дежурств из разных отделений стационара в единый документ Word с трёхколоночным форматом, готовый к печати и утверждению.

## 🎯 Назначение
Программа решает проблему ручного сбора графиков из Excel/PDF файлов (Гинекология, Травматология, Урология, Приемное отделение, ОАР, Хирургия и др.) в один мастер-документ.

## 🚀 Быстрый старт
1. Установите зависимости: `pip install -r requirements.txt`
2. Положите файлы графиков отделений в одну папку.
3. Запустите: `python main.py` (или `Сводный график.exe`)
4. Выберите папку, месяц, год, руководителя и площадку.
5. Нажмите "Составить сводный график". Результат появится в подпапке `Сводный график`.

## 🏗️ Архитектура (v8.0)
- `main.py` — точка входа в приложение.
- `core/` — конфигурация, утилиты, валидация и оркестратор сборки (`schedule_builder.py`).
- `parsers/` — модульные парсеры для разных форматов (стандартный Excel, ОАР, хирургия PDF/TXT, многостраничный Excel).
- `output/` — генераторы выходных файлов (Word, TXT, Excel для проверки).
- `ui/` — графический интерфейс на CustomTkinter.
- `service/docs/` — инструменты генерации документации.

## 📁 Структура данных
- `data/` — игнорируется в git. Содержит тестовые входные данные (`input/`), результаты (`output/`) и архивы.
- `project_info/` — документация и руководства.

## ⚙️ Настройка справочников
В корне проекта лежат файлы, которые можно редактировать в Блокноте:
- `spravochnik_rukovoditeli.txt` — список руководителей (формат: `Должность|ФИО`).
- `spravochnik_ploshadki.txt` — список площадок (по одной на строку).
