# 📊 Сводный график дежурств

Автоматическое объединение графиков дежурств из отделений в единый документ.

## 🎯 Назначение

Программа собирает графики дежурств из разных отделений (Гинекология, Травматология, Урология, Приемное отделение, ОАР и др.) в один сводный документ Word с трёхколоночным форматом.

**Результат:**
- 📄 Word-документ с шапкой и утверждением
- 📄 TXT-файл для быстрой проверки

## 📦 Системные требования

| Параметр | Требование |
|----------|------------|
| ОС | Windows 7 / 8 / 10 / 11 |
| Установка | Не требуется (портативная версия) |
| Права администратора | Не требуются |
| Место на диске | ~100 МБ |
| Дополнительное ПО | Microsoft Word (для просмотра .docx) |

## 🚀 Быстрый старт

1. Положите все файлы графиков в одну папку
2. Запустите `Сводный график.exe`
3. Нажмите "Обзор..." и выберите папку
4. Выберите месяц и год
5. Выберите руководителя и площадку
6. Нажмите "Составить сводный график"
7. Результат — в папке `Сводный график`

## 📁 Поддерживаемые форматы

| Формат | Расширение | Примечание |
|--------|------------|------------|
| Excel | `.xlsx`, `.xls` | Основной формат |
| CSV | `.csv` | Экспорт из Excel |
| PDF | `.pdf` | Только для хирургии |
| TXT | `.txt` | Только для хирургии |

## 📝 Структура файла графика

| График дежурств врачей | Отделения | на | Август | 2026 |
| Дата | 1 авг | 2 авг | 3 авг | ... |
| Дежурный врач | Сб | Вс | Пн | ... |
| Иванова А.А. | 9-9 | | 16-9 | ... |
text


**Поддерживаемые форматы времени:**
- `9-9` — с 9:00 до 9:00
- `16-9` — с 16:00 до 9:00
- `8:30-8:30` — с 8:30 до 8:30

**Важно:** имя файла может быть любым — программа определяет отделение по содержимому шапки!

## ⚙️ Настройка справочников

Рядом с программой лежат файлы для редактирования в Блокноте:

- `spravochnik_rukovoditeli.txt` — список руководителей (формат: `Должность|ФИО`)
- `spravochnik_ploshadki.txt` — список площадок (по одной на строку)
