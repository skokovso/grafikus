# Журнал изменений

Все значимые изменения в проекте "Сводный график дежурств" будут отражены в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

---

## [7.1] — 2026-07-25

### 🎯 Текущая стабильная версия

#### ✨ Добавлено
- Отображение списка исключённых файлов в интерфейсе (не только в логе)
- Цветовая индикация статуса: зелёный — успех, красный — ошибка, оранжевый — предупреждение
- Обработка ошибки "файл открыт в Word" с понятным сообщением для пользователя
- Иконка приложения в окне и на панели задач Windows
- Кнопка "Очистить" для сброса статуса
- Показ списка исключённых файлов в статусной строке

#### 🔧 Изменено
- Интерфейс полностью переработан на CustomTkinter (современный дизайн, тёмная тема)
- Увеличен размер статусной строки для отображения списка исключённых файлов
- Оптимизировано распределение дней по трём колонкам на странице (48 строк для первой страницы, 59 для остальных)
- Улучшен парсинг хирургии из PDF (поддержка объединённых ячеек)
- Корректная привязка дат в PDF-хирургии
- Улучшено определение отделений по содержимому файла

#### 🐛 Исправлено
- Исправлена ошибка "not enough values to unpack" при возврате из build_master_schedule
- Исправлена ошибка с tag_config в CTkTextbox
- Исправлен баг с пустой страницей при формировании Word-документа
- Исправлена проблема с дублированием врачей из разных отделений
