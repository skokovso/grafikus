# Changelog — Grafikus

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [8.1.1] — 2026-10-07 — администрация

### Added

- **Парсер администрации** (`parsers/administration.py`): чтение графика
  административных обходов с фильтрацией по площадке
  (`Ломоносова, д.18` / `Володарского, д.18` / `Перинатальный центр` /
  `Родильный дом`). Значения в колонках — `datetime` из
  `pandas.read_excel` (Excel сохраняет кэш вычисленных формул).

### Changed

- **Порядок отделений** (`core/config.py`): `'АДМ'` добавлен **первым** в
  `DEPARTMENT_ORDER` — администрация идёт сразу после даты и дня недели.
- **Вывод администрации**: без времени, формат `ФИО (АДМ)`;
  в TXT — со звёздочкой `* ФИО (АДМ)`; в Word — **жирным шрифтом**.
- Значение в `all_data` для администрации изменено с `'Адм'` на `''`.

### Fixed

- **Администрация:** парсер возвращал 0 строк — в проверке типа было
  `isinstance(date_val, (pd.Timestamp, pd.DatetimeTZDtype))`,
  что не срабатывает на обычных `datetime` из `pandas.read_excel`.
  Заменено на `isinstance(date_val, (datetime, pd.Timestamp))`,
  добавлен `from datetime import datetime`.
- **Артефакт «А дм»** в выводе: значение `'Адм'` ошибочно
  интерпретировалось как буква смены `'А'` + время `'дм'`.
- **Word:** жирный шрифт для ФИО администрации не срабатывал —
  проверка `' (АДМ) '` не находила `'(АДМ)'` без пробелов. Заменена
  на `'(АДМ)' in line`.

## [8.1] — 2026-10-06 — стабилизация после рефакторинга

### Added

- Генератор документации переведён на Word-путь (как в sonolog):
  `USER_MANUAL.md` → `USER_MANUAL.docx` (python-docx + логотип) →
  `USER_MANUAL.pdf` (docx2pdf через Word). Fallback — fpdf2.
- Новый набор проектных документов в корне: `DIGEST.md`, `DEVLOG.md`,
  `TODO.md`, `QWEN.md` (в дополнение к README/AI_BRIEF/ARCHITECTURE/
  CHANGELOG).
- Папка `assets/` — логотип `project_logo.png` и иконка
  `project_logo.ico`; поддержан откат на корневой `icon.ico`.
- `service/run.py` — единый запускатель служебных скриптов.
- `service/docs/ai_pack.py` — упаковка проекта для чата с ИИ.

### Changed

- `ui/app.py` вынесен из монолита `grafikus.py` (v8.0 → v8.1 чистка
  дублей и «хвостов» старой логики).
- `service/docs/make_docs.py` больше не создаёт двойную папку
  `project_info/manuals/manuals/`.

### Fixed

- Двойная папка `manuals/manuals/` при генерации USER_MANUAL.md.

## [8.0] — 2026-10-01 — модульный рефакторинг

### Added

- Проект разбит на модули: `core/`, `parsers/`, `output/`, `ui/`
  (вместо монолитного `grafikus.py`).
- Экспорт в Excel (`.xlsx`) — плоская таблица для аудита и фильтрации.
- Улучшенный парсер хирургии: PDF через `pdfplumber.extract_tables()`
  — корректная обработка сдвоенных ячеек.

### Fixed

- **Критично:** слово «Код» в шапке больше не удаляет врачей с фамилией
  «Кодиров».
- PDF-хирургия: оба врача одного дня (например, Долгалёв и Рихан)
  больше не «переезжают» на следующий день.
- ОАР: буква смены (А/Р/Э) ставится **перед** временем
  (`А 16-09`, а не `16-09А`).
- Поиск месяца в заголовках регистронезависим (`Октябрь/октябрь/ОКТЯБРЬ`).

## [7.1] — 2026-07-25 — текущая стабильная (монолит)

### Added

- Список исключённых файлов в интерфейсе (а не только в логе).
- Цветовая индикация статуса: зелёный / красный / оранжевый / синий.
- Понятное сообщение при `PermissionError` (файл открыт в Word).
- Иконка в окне и на панели задач Windows.
- Кнопка «Очистить» для сброса статуса.

### Changed

- Интерфейс полностью на CustomTkinter (тёмная тема).
- Увеличен размер статусной строки.
- Оптимизировано распределение дней по колонкам (48/59).
- Улучшен парсинг хирургии (объединённые ячейки).

### Fixed

- `not enough values to unpack` при возврате из `build_master_schedule`.
- `tag_config` в `CTkTextbox`.
- Пустая страница при формировании Word.
- Дубли врачей из разных отделений.
